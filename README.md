# GlowMind Starter (Expo + React Native)

This repository now contains a starter scaffold for the GlowMind app, including:

- Expo Router tab layout
- Home, Routine, Mood, and Reminders screens
- Shared color palette
- Routine, mood, and reminders seed data
- Notification and AsyncStorage utilities
- Reusable UI component shells
- Simple hooks for routine progress and mood history

## Next steps

1. Create a fresh Expo app and copy these files in.
2. Install dependencies from your guide.
3. Run `npx expo start`.
